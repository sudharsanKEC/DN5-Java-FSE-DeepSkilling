What is the Data Access Module?
      The Data Access Module provides the infrastructure required for interacting with databases and managing transactions.
      Instead of writing large amounts of JDBC boilerplate code, Spring offers a cleaner and more consistent way to perform database operations.
      In simple words: The Data Access Module acts as a bridge between your Java application and the database.

      Why was this module introduced?
            Without Spring, using JDBC involved a lot of repetitive code:
                  Connection connection = null;
                  PreparedStatement statement = null;
                  ResultSet resultSet = null;
                  try {
                      connection = DriverManager.getConnection(...);
                      statement = connection.prepareStatement(...);
                      resultSet = statement.executeQuery();
                  
                      // Process data
                  
                  } finally {
                      resultSet.close();
                      statement.close();
                      connection.close();
                  }

            Problems:
                  Lots of boilerplate code
                  Manual resource management
                  Manual transaction management
                  Repetitive exception handling
            Spring simplifies these concerns.

            Responsibilities of the Data Access Module
                  Database connectivity
                  Transaction management
                  JDBC abstraction
                  ORM integration (Hibernate, JPA)
                  Exception translation
                  Resource management

1. spring-jdbc
      Purpose
          Provides a higher-level abstraction over JDBC.
      Instead of managing:
          Connections
          Statements
          ResultSets
          Resource closing
      Spring handles them automatically.
      Example
          Without Spring:
                Connection connection = ...
                PreparedStatement statement = ...
                ResultSet rs = ...
          With Spring:
                jdbcTemplate.query(...);
          Much shorter and safer.
      Important Class
              JdbcTemplate
      It handles:
              Opening connections
              Executing SQL
              Closing resources
              Exception handling

      Spring Boot Developer
              Nowadays, if you're using Spring Data JPA, you may rarely use JdbcTemplate.
              However, it's still useful for:
                  Native SQL queries
                  High-performance database operations
                  Stored procedures

2. spring-tx (Important)
      Purpose
          Provides Transaction Management.
          Imagine transferring money:
                  Deduct ₹100
                  ↓
                  Add ₹100
          If the second operation fails,
          the first one must also be undone.
          This is called a Transaction.
          Spring manages this automatically.
          Example
                @Transactional
                public void transferMoney() {
                }
          Behind the scenes,
          Spring starts,
          commits,
          or rolls back the transaction.

      Spring Boot Developer
            This is one of the most important libraries.
            You'll use:
                @Transactional
            very frequently.

3. spring-orm 
      Purpose
          Integrates Spring with ORM frameworks.
      Examples:
          Hibernate
          JPA
          MyBatis (through separate integration)
      Instead of writing SQL manually,
          you can simply write:
                userRepository.save(user);
          and Hibernate generates SQL behind the scenes.

      Spring Boot Developer
            This is the library you'll indirectly use every day through:
                        Spring Data JPA
                        Hibernate

4. spring-oxm
          Purpose
              OXM = Object XML Mapping
          Converts
                Java Object
                ↕
                XML
          Useful when working with SOAP services or XML-based integrations.
          Spring Boot Developer
                Rarely used unless you're working with legacy enterprise systems.


5. spring-jms
        Purpose
            Supports Java Message Service (JMS).
            Used for asynchronous communication through message brokers.
        Example:
              Application
              ↓
              RabbitMQ / ActiveMQ
              ↓
              Another Application

          Spring Boot Developer
            Useful in:
                  Microservices
                  Event-driven systems
                  Asynchronous processing
            Not commonly used in beginner CRUD applications.

Notice that as a Spring Boot developer, you often work with Spring Data JPA, but underneath it, several lower-level libraries from the Data Access module are doing the actual work.
    Important: Spring Data JPA is not part of the Spring Framework's Data Access module. It belongs to the separate Spring Data project, which is built on top of the Spring Framework. Spring Data JPA internally uses the Data Access module (especially spring-orm and spring-tx) to provide repository abstractions and transaction support.



Note: the two libraries you should understand best are spring-tx (transactions) and spring-orm (ORM integration). These form the foundation of how Spring Boot works with databases.
